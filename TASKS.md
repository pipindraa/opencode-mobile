# Задачи по приложению (список от владельца, 30.10.2026)

Живой тест на телефоне недоступен (Omnirush сервер требует обновления, ADB отвалился),
поэтому правим код и собираем APK без проверки на устройстве. Статусы обновляются по ходу.

## 1. Индикатор «запрос работает»
Сейчас в чате виден только маленький спиннер в хедере, в остальном — тишина.
Нужно: заметный статус процесса (думает / печатает / вызывает инструмент / ждёт разрешения),
таймер, плавные «бегущие» точки, блокировка кнопки отправки без объяснений.

## 2. Отправка картинок с телефона
Нет выбора фото и вложений. Нужно: кнопка 📎 → галерея → превью → отправка вместе с текстом.
Разобраться, как это принимают оба API (OpenCode v2 и форк Omnirush).

## 3. Клавиатура перекрывает поле ввода
При открытии клавиатуры панель ввода уезжает под неё. Нужно как в Telegram:
панель ввода поднята над клавиатурой, лента сообщений сжимается, а не уезжает.

## 4. Авто-обновления без похода к разработчику
Хочется ставить новую версию прямо из приложения. Кандидат — GitHub Releases
(gh CLI уже залогинен как pipindraa). Проверить варианты лучше GitHub-релизов.

## 5. Заголовок чата
Сверху написано «kiril» (это имя пользователя). Нужно имя/название чата.

## 6. Свайп вправо из чата → список чатов
Свайп от левого края вправо (как «назад» в iOS). Сейчас выйти можно только кнопкой
«‹ Назад» и системной кнопкой Android.

## 7. Tailscale убивает интернет на телефоне
Без VPN не подключиться, с VPN — интернета нет. Продумать альтернативы
(раздельное туннелирование, собственный туннель, другой транспорт).

## 8. Откат сообщений и отмена текущего запроса
- Откат (revert) как в OpenCode: удалить сообщения начиная с последнего запроса.
- Отмена (как Esc Esc): мгновенно остановить агента.
